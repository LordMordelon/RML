# Glosario: ReGrowth: Boiling

Términos de este módulo de ReGrowth (el bioma «bosque hirviente»). Se armó el 30-oct-2026, al
traducirlo por primera vez. Sigue al de ReGrowth 2,
[GLOSARIO-REGROWTH.md](../ReGrowth%202%20-%202260097569/GLOSARIO-REGROWTH.md), y los dos los manda
[RML/GLOSARIO.md](../../../GLOSARIO.md).

Las etiquetas (`label`) van en minúscula, como en la traducción oficial. Lo que el mod copia del juego
va con el texto oficial.

| Inglés | Español | Notas |
|---|---|---|
| boiling forest | **bosque hirviente** | **Angel, 30-oct.** Como «bosque templado» y «bosque boreal» |
| boiling (lluvia) | **hirviente** | «llovizna hirviente», «lluvia hirviente», «niebla lluviosa hirviente», «tormenta hirviente». La oficial: «niebla lluviosa», «tormenta lluviosa» |
| deals burn damage | **causa quemaduras** | Oficial: el daño `Burn` es «quemadura» |
| hot spring / deep hot spring | **fuente termal** / **fuente termal profunda** | Como el resto de RML. La oficial usa «aguas termales» para el rasgo del mapa y «fuentes termales» para el lugar del mundo |
| owlbeast | **osolechuza** | **Angel, 30-oct.** Mezcla de oso pardo y lechuza; es el nombre en español de esta criatura en los juegos de fantasía. Masculino: «es nocturno». Su descripción sigue a la del oso pardo oficial |
| boilberries / boilberry bush | **bayas hirvientes** / **arbusto de bayas hirvientes** | Su descripción sigue a la de las bayas y el arbusto de bayas oficiales |
| grass / tall grass | **hierba** / **hierba alta** | Oficial. Las descripciones, también |
| brambles | **zarzales** | Oficial, con su descripción |
| moss / bush | **musgo** / **arbusto** | Oficial. «Normalmente no habla», como el juego |
| birch tree / pine tree | **abedul** / **pino** | Oficial |
| spike-bark tree | **árbol de corteza espinosa** | |
